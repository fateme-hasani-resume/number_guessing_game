
# Number Guessing Game

## Description
A simple interactive Python game in which the computer
selects a random number between 1 and 20.
The player tries to guess the selected number.

## Features
- Random number generation
- Interactive user input
- Higher and lower hints
- Attempt counter
- Automatic game termination after a correct guess

## Concepts Learned
- Importing modules
- Random module
- While loops
- If, elif and else
- Break statement
- Counter variables

## How to Run

Run the following command:

python number_guessing_game.py

## Example

The computer selects a random number.
The player receives hints until the correct number is guessed.
